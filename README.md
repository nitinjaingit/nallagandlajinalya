# Shree Digambar Jinalya, Nallagandla, Hyderabad Website

A professional, responsive, database-free temple website. It uses plain HTML, CSS, and JavaScript, so there is no build step or server-side API.

## Preview

Open `index.html` directly in a browser. The website has separate pages for Home, Events, About, Gallery, Visit, Contact, and Donation.

## Add Your Photos

1. Open `manage-images.html` in Chrome or Edge.
2. Choose or drag in one or more JPG, PNG, or WebP photos.
3. Edit captions, arrange the order, and select a home-page photo.
4. Choose **Preview gallery** to check the result in the same browser.
5. Choose **Save website file** and save over the existing `image-data.js` in this folder.

The manager resizes large images to a maximum of 1600 pixels and compresses them for faster loading. The generated `image-data.js` contains the photos, so publishing remains file-based and does not require image hosting or a database.

As an alternative, put image files in `assets/images` and reference those paths directly from `content.js`.

## Update Content

All frequently changed content is in `content.js`:

- Temple name, description, timings, address, phone, and email
- Announcement ticker messages
- Upcoming and past events
- Gallery images and captions
- Donation and map links

The `image-data.js` file is generated by the photo manager and should normally not be edited by hand.

## Publish

Upload the complete folder to any static host such as GitHub Pages, Azure Static Web Apps, Netlify, Cloudflare Pages, or a traditional web host. No database is required.

## Recommended Content Before Launch

- Replace the sample temple name and contact details.
- Add original temple and event photographs with meaningful captions using the photo manager.
- Confirm daily and festival timings.
- Add the committee-approved donation method and receipt instructions.
- Add social media links only for actively maintained accounts.
- Add a privacy note if a future form collects visitor information.
